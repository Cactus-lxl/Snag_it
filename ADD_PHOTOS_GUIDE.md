## 🐛 TROUBLESHOOTING:

### **"Permission denied"**
1. Close app
2. Go to Settings → Expo Go
3. Enable Camera & Photos
4. Restart app

### **"Module not found"**
1. Close terminal
2. Run `add-photos-back.bat` again
3. Run `npx expo start -c`

### **Photos not showing**
1. Shake phone
2. Tap "Reload"
3. Try again
